# LaTeX CV Setup

A simple and automated LaTeX CV project designed to make CV creation and compilation easy.

The project provides:

- LaTeX CV template
- Automated environment setup
- Git and GitHub integration
- Visual Studio Code configuration
- LaTeX Workshop integration
- Automatic CV compilation
